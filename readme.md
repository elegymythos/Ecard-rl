# 皇帝牌（E卡）自博弈 PPO：它到底是什么

> 这个项目真正研究的不是「皇帝牌的均衡」——均衡是数学题，手算就能解。
> 它研究的是：**在非对称收益和自博弈下，PPO 这个梯度下降物种会停在哪里，以及为什么。**

## 一句话结论

在皇帝胜 +1、皇帝负 -5、第 5 轮强制王牌的设定下，自博弈 PPO 没有收敛到博弈论均衡（双方出王牌概率 1/7），
而是停在了一个「皇帝赢了 79.7% 的局、期望收益却是 -0.217」的吸引子上。

这不是偶然，是**优势归一化抹掉奖励尺度**的直接后果。理解这件事，是这个项目真正的产出。

## 研究问题

1. 自博弈 PPO 在这里最终停在哪里？—— p=0.294、q=0.456（均衡是 0.143）
2. 为什么皇帝胜率 79.7% 却期望为负？—— 优势归一化把 -5 的惩罚稀释成了「批内相对优劣」
3. 它收敛了吗？—— 单次运行内稳定（末段漂移 ±0.0003）；多 seed 未验证，不能推广为一般结论

## 游戏规则

* 皇帝：1 张皇帝牌 + 4 张平民牌；奴隶：1 张奴隶牌 + 4 张平民牌
* 每轮双方同时亮牌；王牌相遇立即分胜负：奴隶王牌 vs 皇帝王牌 → **奴隶胜**
* 其余任何一张王牌出现（皇帝 A vs 平民 C，或平民 C vs 奴隶 A）→ **皇帝胜**
* 平民对平民 → 平局，进入下一轮；第 5 轮强制双方出王牌（A-A → 奴隶胜）

收益矩阵（皇帝视角）：

| 皇帝\奴隶 | 出王牌 A | 出平民 C |
| :---: | :---: | :---: |
| **出王牌 A** | -5（奴隶胜） | +1（皇帝胜） |
| **出平民 C** | +1（皇帝胜） | 0（平局） |

同一结果在奴隶视角为相反数（奴隶胜 = +5，皇帝胜 = -1）。

## 已知答案：均衡

单轮静态混合纳什均衡：双方出王牌概率都是 **1/7 ≈ 0.143**，皇帝期望收益 **+1/7 ≈ +0.143**。

推导：皇帝出 A 概率 p、奴隶出 A 概率 q，期望收益 E(p,q) = p + q − 7pq；
令 ∂E/∂p = ∂E/∂q = 0，得 p = q = 1/7。

注意：1/7 是单轮静态近似。带第 5 轮强制的完整序贯博弈应使用**逆向归纳**求解——
本仓库尚未实现，这是下一步。

## 关键结果（2026-08-08，单次运行，seed=42，6M 回合）

| 指标 | 值 | 对照 |
| :--- | :---: | :---: |
| 皇帝胜率 | 0.7972 | — |
| 奴隶胜率 | 0.2028 | — |
| 皇帝期望收益 | **-0.217** | 均衡 +0.143 |
| 皇帝初始出王牌概率 p | 0.2936 | 均衡 0.1429 |
| 奴隶初始出王牌概率 q | 0.4556 | 均衡 0.1429 |
| 平均结束回合 | 2.94（中值 1.7） | 分布右偏 |
| 末段漂移（最后 5%） | -0.0003 / +0.0001 | 单次运行内稳定 |
| 第 5 轮强制 A-A 局占比 | 4.0% | 241,636 / 6,000,000 |

**可复现性声明**：上述数字来自 2026-08-08 的一次运行；`data/`、`swanlog/` 均未入库，
多 seed 复核未做。「收敛」目前只意味着「单次运行最后 5% 窗口内稳定」，不是分布意义上的结论。

## 结果意味着什么

**皇帝没有在 best respond。** 给定奴隶 q=0.4556，皇帝的最优反应是永远不出王牌（p=0，期望 +0.456）；
它停在 p=0.294，静态近似期望约 -0.19（实测 -0.217，差异来自序贯结构）。
也就是说，PPO 找到的不是均衡，是算法自己的吸引子。

**为什么：优势归一化。** PPO update 对优势做了减均值除标准差，把 +1 与 -5 的绝对尺度差抹掉了。
皇帝学到的不是「输一把亏五倍」，而是「这批样本里相对好一点」。
旧代码注释里承认了这一点，但旧 README 没有这段分析——本文件补上了这个空缺。

**「对手建模」不是对手建模。** 自博弈中双方信息对称，注入状态的 5+5 维全局 hazard 率
是双方的共同知识，不是对「另一个不同的人」的建模。

## 这个项目不是什么

* 不是皇帝牌博弈的求解器：均衡是数学题（1/7 / 逆向归纳），不需要 RL
* 不是赌徒心理的模拟：没有损失厌恶、概率权重、追回本——梯度下降不 feel 损失
* 不是生产级 RL 库：`ppo.py` 有 1758 行，大部分是检查点、SwanLab、防御分支等脚手架
